# 第8周作答：任意大于2的偶数都是两个素数之和

## 题目与作答对象

待证命题是：对每一个整数n，若n>2且n为偶数，则存在素数p、q使n=p+q。

本仓库提交该命题的数学证明尝试，按题目要求包含相关定义、引理、详细推导和最终结论。论证从R_prime(n)>0的等价条件出发，经圆法分解、主弧实部下界、次弧相关和、高次素数幂剥离，回到二素数表示。全部为纯文本数学内容。

## 阅读顺序

proof/part-01.md：定义、引理1–3、主弧误差的有限公式。
proof/part-02.md：引理4–6、旧次弧常数的区间反算及Type II有效上界。
proof/part-03.md：引理7、有限证书定理及正性条件。
proof/part-04.md至part-08.md：4≤n≤10000的4999项素数证书。
proof/part-09.md：新增定理10，完整推导充分大n时的无条件主弧下界I_M≥0.8 S(n)n；随后给出全称命题的剩余次弧条件及两项几何、范数校正。
